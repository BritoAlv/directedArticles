# Principal Component Analysis:

## Problem Formulation Orthogonal Transformations:

In $R^n$, the standard basis is made by the $n$ vectors $e_1, e_2, ..., e_n$. 

Start with a vector $v$ with $n$ coordinates, i.e. a point on the subspace spanned by the vectors $e_1, e_2, ..., e_n$.

$v$ can be written as:

$$v = \langle v, e_1 \rangle e_1 + \dots + \langle v, e_n \rangle e_n$$

Also, by Pythagoras:

$$\|v\|^2 = |\langle v, e_1 \rangle|^2 + \dots + |\langle v, e_n \rangle|^2$$

Sort the values $|\langle v, e_i \rangle|^2$ from biggest to lowest, so that:

$$\|v\|^2 = |\langle v, e'_1 \rangle|^2 + \dots + |\langle v, e'_n \rangle|^2$$

Fix $0 < d < n$, and consider the prefix sum:

$$|\langle v, e'_1 \rangle|^2 + \dots + |\langle v, e'_d \rangle|^2, \text{ observe that's } \leq \|v\|^2.$$

An orthogonal transformation to the axis vectors gives a new set of axis $k_1, k_2, ..., k_n$ where the same three step can be done:

$$\|v\|^2 = |\langle v, k_1 \rangle|^2 + \dots + |\langle v, k_n \rangle|^2$$

Sorting:

$$\|v\|^2 = |\langle v, k'_1 \rangle|^2 + \dots + |\langle v, k'_n \rangle|^2$$

And finally consider the prefix sum:

$$|\langle v, k'_1 \rangle|^2 + \dots + |\langle v, k'_d \rangle|^2$$

The catch is that $\|v\|$ didn't change during the transformation, so a natural question is: 

From all the orthogonal transformation that can be applied to the standard basis vectors, which one maximizes the number:

$$|\langle v, k'_1 \rangle|^2 + \dots + |\langle v, k'_d \rangle|^2$$

See that the vector $\langle v, k'_1 \rangle k'_1 + \langle v, k'_2 \rangle k'_2 + \dots + \langle v, k'_d \rangle k'_d$ is the projection of $v$ in the subspace spanned by the vectors $k'_1, k'_2, k'_3, \dots, k'_d$. 

$v$ is being expressed as the sum $v = v_{k'} + (v - v_{k'})$, by Pythagoras $\|v\|^2 = \|v_k\|^2 + \|v - v_k\|^2$, $\|v\|$ is constant under the orthogonal transformations. 

Because $v_k$ is the projection of $v$ in the space spanned by $d$ orthonormal vectors. 

The problem can be formulated as finding the subspace of rank $d$, where the length of the projection of $v$ in this space is the largest, or equivalently, the difference $\|v - v_k\|^2$ is smallest as possible. 

The insight here is that: 

$v$ is a vector in $R^n$, and the goal is build an approximation of it using at most $d$ vectors. 

Makes no sense use less than $d$ vectors, because each vector gives a new axis where $v$ can be projected, and thus the length of that contributed can be added to the total.

The approximation will be its projection in the subspace generated by those $d$ vectors, by Pythagoras $\|v\|^2 = \|v_k\|^2 + \|v - v_k\|^2$. 

Because $\|v\|$ is fixed, means that the approximation error $\|v - vk\|^2$ has to be minimized, or equivalently maximize $\|v_k\|^2$. That's using $\|x-y\|^2$ as a measure of the distance between two vectors.

The number $\|v_k\|^2$ does not depend on the basis used to represent the subspace.

The problem stated this way makes no sense, choose as a direction precisely $v$, the projection will be itself, and trivially that's the maximum.

The difficulty of the problem arises when the number of vectors to approximate is not one, the problem formulation is the same, but summing over all the vectors in the dataset:

$$\sum_{v \in D} \|v\|^2 = \sum_{v \in D} \|v_k\|^2 + \sum_{v \in D} \|v - v_k\|^2$$

If in the dataset there are $m$ vectors, then the problem is about find the subspace spanned by $d$ vectors that minimizes the sum of the approximation error per vectors, or maximizes the sum of the square lengths of the projections (approximations). Keep in mind that for all the vectors the same transformed features or axis are used. 

As long as $m \leq d$, the problem is trivial. The space spanned by those $m$ vectors has rank at most $d$, so one can represent it with an orthogonal basis, and the approximation of each vector will be itself, because it lies on the subspace. The challenge is when $m \gg d$.

## Matrix That Represent the Projection

How to represent with matrices the process that's going on:

An orthogonal basis of rank $d$, that lives in $R^n$, is indicated by $d$ column vectors orthonormals, $M'$ $n \times d$. The projection matrix of the projection linear transformation on the subspace spanned by those vectors, that matrix is $(M')^T = M$, dimensions of $M$ are $d \times n$.

See here, start with $v$ a column vector in $R^n$, apply $M^T$ to it, one obtains $M^Tv$ $d \times 1$, those are the coefficients of the projection of $v$ in the subspace spanned by $M'$, the actual vector on the standard basis is $M' (M^T v)$.

The goal then, is find $M'$. $n \times d$ orthonormal column vectors, that maximizes: $\sum_{v \in D} \|M' M^T v\|^2$ or minimizes: $\sum_{v \in D} \|v - M' M^T v\|^2$

## Variance Interpretation

If the data is assumed to be centered at $0$, the mean of each feature is $0$, then the sum of the squared lengths per coordinate, can be interpreted as the sum of the variances of each feature if scaled by $\frac{1}{N}$. 

The variance of a feature in the dataset is precisely the sum of the squared lengths of the projection on that axis (feature).

The sum of the variances per feature is not changed by the orthogonal transformation, this means the sum of the variances of the initial features is the same as the sum of the variances of the transformed features. This allows to formulate the problem as finding the top d directions that most variance concentrate.

Note that the mean of the dataset is still $0$ after the transformation, and that the dataset can be centered at $0$ by subtracting its mean before doing this analysis without losing generality.

## Difference with Least Squares

In the least squares problem the subspace is fixed, and the question is find the best approximation of a vector $b$ in that space, the answer turns out to be the projection of that vector in that subspace. In this problem the input is a set of vectors, and a number $d$, the question is find the subspace of rank at most d, that best approximates those vectors. Where the approximation of a vector with a subspace is its projection in that space.
